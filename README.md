# ColabDoc

Real-time collaborative document editor inspired by Google Docs.

## Features

- Realtime Collaboration
- Laravel Reverb WebSocket
- MongoDB Database
- Autosave
- Version History
- Restore Revision
- Presence System
- Google Docs-like UI

## Tech Stack

- Laravel 13
- Vue 3
- Inertia.js
- MongoDB
- Tailwind CSS
- Tiptap Editor
- Laravel Reverb
